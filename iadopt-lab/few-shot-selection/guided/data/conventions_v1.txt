Matrix
1. First name the object of interest: the entity whose property is measured. Ask every matrix question about that entity.
2. If the only candidate container is the object of interest itself, there is no matrix. Example: the wingspan of an albatross: the object is the albatross; no matrix.
3. If the object is a ratio "X in Y" (a concentration, fraction or content of X in Y, or X per Y), Y belongs to the object as its denominator and is never the matrix. A matrix is only something further that holds Y. Example: zinc content of river sediment: object zinc / sediment, no matrix. Example: zinc content of the sediment of a harbour basin: object zinc / sediment, matrix harbour basin.
4. If the object belongs to a person (a body part or fluid, a substance in the body, a physiological signal, a life event, a condition, a behaviour or a status) without being the person, the matrix is the person (natural container). Example: cortisol in saliva, the number of dentist visits per year, or marital status: matrix person. Example: a person's own height: the object is the person; no matrix.
5. Otherwise, if the object is inside, part of, or carried by a nearer named thing, that thing is the matrix: a natural body (a lake, an ocean, the seabed, the earth, a tree, an organism, the atmosphere for air and wind) is a natural container; a made structure or vessel (a building, a ship, a tank, a pipe) is an artificial container; a different material the object is embedded in (sediment, rock, a liquid sample) is an embedding material. Example: the number of beds of a hospital: object bed, matrix hospital (artificial container).
6. Only the nearest container is the matrix; a further, outer one is the context object. A container of the same material as the object is a context object, not a matrix. Example: salt crystals in sea spray in the atmosphere: matrix sea spray, context object atmosphere.
7. If the object moves from one compartment to another (a flux, deposition, uptake or discharge), the matrix is the flow from source to target. Example: nitrogen uptake from soil into roots: matrix soil to root (flow).
8. If the quantity is an index, a risk or a count defined over a study area (a district, a city, a catchment), the matrix is that area (reference area). Example: noise complaints per neighbourhood of a city: matrix urban area. Counts of people living in a statistical unit take the area as the context object instead.
9. A process is the matrix only when nothing else holds the object; otherwise it is a constraint of the type "process". Example: heat released by burning wood: matrix combustion. Example: oxygen produced during photosynthesis of a leaf: matrix leaf, constraint process: photosynthesis.

Constraints
10. First write every phrase of the definition that narrows the variable into "restrictions": adjectives (dissolved, frozen, resting, dry), phrases with at, under, per, during, from, near, due to or without, and frequency words (daily, hourly). The property, the object of interest, the matrix and the statistical modifier (mean, maximum, standard deviation) are not restrictions. Then give each restriction one type, by these contrasts.
11. A temperature, pressure, wavelength or standard at which the value is measured is a condition ("at 25 °C", "under ISO test conditions"). A range that decides which part of the object counts has its own type ("radiation between 400 and 700 nm": wavelength; "nights with a minimum temperature above 15 °C": min temperature).
12. A value divided by a unit, or counted per period, is a normalization ("per hour", "per household", "during the last 7 days" for a count). A statistic computed over a period is a temporal extent ("over the survey period"). How often a value is reported is a reporting frequency ("daily", "hourly").
13. The condition or phase of the constrained entity, said as an adjective, is a state (dissolved, dry, frozen, stagnant, inactive). The form a substance takes is a physical form (snow, hail, ice). A mode of movement is a locomotion state (resting, walking).
14. "Due to X", the hazard behind a risk, stress or damage, is a cause ("damage due to hail"). An ongoing natural or bodily process during which the value is taken is a process ("during digestion", "during photosynthesis"). A single occurrence that bounds or triggers the value is an event ("the latest test", "a 50-year storm"). Where something comes from is a source ("from road traffic", "emitted by a power plant").
15. A portion of the entity where the value is taken is a part ("surface", "upper layer", "near surface"). A point or line the value is measured from or against is a reference ("above ground", "relative to magnetic north", "relative to the sensor").
16. A rule that decides which value counts is a criterion ("the highest degree", "at the detection limit"). A grade on a standard scale is a rating ("five star"). A rank is an order ("secondary").
17. About a person: role (tenant, student), relationship (father), age (over 18), education, agent (accredited laboratory), purpose (screening for influenza), time (current).
18. "Deionized water" always carries the constraint "resistivity: > 1 MOhm cm" on the water.
